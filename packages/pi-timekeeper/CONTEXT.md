# pi-timekeeper

Codex 式时间感知 extension：在 run 边界以拉式注入时间锚，让模型知道"现在"，且绝不唤醒空闲会话、绝不触碰 system prompt。

## Vocabulary

- **时间锚 (anchor)**:
  注入到对话上下文的一行时间事实（日期/星期/时刻/时区），模型时间感知的原子单位。
  _Avoid_: 时间提醒（那是节流条件名）、time line
- **拉式注入 (pull)**:
  时间锚只在 run 边界按需计算投递——LLM 调用本就要发生的时刻才可能注入；结构上不存在唤醒空闲会话的路径。
  _Avoid_: timer 推送、push 注入
- **run 边界**:
  一次用户 prompt 触发的完整 agent 工作（agent_start→agent_end）的开始处；拉式注入唯一的发生点。一次 run 内部由多个 turn（LLM 调用 + 其 tool call）组成。
- **diff-date 条件**:
  本地日历日期相对上次锚定发生变化时触发的节流条件；常开，无开关。
- **reminder 条件**:
  距上次锚定超过 interval（默认 1h）触发的节流条件；可通过环境变量整体关闭。
  _Avoid_: 定时提醒（暗示 timer，本设计无 timer）
- **no-catch-up**:
  长时间未注入后，错过的 interval 不逐条补发，合并为下一次注入的一条锚。
- **重锚 (re-anchor)**:
  上下文压缩后旧锚可能随摘要丢失；压缩完成即置强制标志，下一个 run 无条件注入一条，两个节流条件的状态随之刷新（reminder 关闭时其字段不刷）。
  _Avoid_: 强制刷新、force（实现符号）
- **状态存档**:
  持久化在 session tree 侧、不进 LLM 上下文的节流状态；与锚严格分离——锚进上下文，存档不进。
  _Avoid_: 快照（早期讨论中与"锚的持久化"混用）
- **无边界拉伸段**:
  一段没有任何 run 边界的连续工作区间；拉式注入在其中不触发，锚保持冻结。
- **冻结上限 (ceiling)**:
  观测到的最长无边界拉伸段时长（本仓实测 7.12h）；拉式设计的已知盲区度量，超出满足度预期时才启用升级路径（per-turn transient 补）。
