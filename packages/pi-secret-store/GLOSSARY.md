# GLOSSARY — pi-secret-store

凭证存储与泄漏执法扩展的领域词汇。词条只述语义与边界，不含实现细节；实现与行为锁定见 `lib/` 与 `tests/`。

- **选择性注入**：bash 命令引用了已存凭证变量时，只把「被引用且仍存在」的凭证 export 进该次命令执行的注入方式。未引用不注入，未存名静默跳过，只缩注入半径不防变量外显。
- **引用**：命令文本中的 `$NAME` / `${NAME}` 形态——命令将消费该变量的信号，是注入的授权依据。
- **展开式引用**：`${NAME:-def}` 等「引用 + 参数展开操作符」形态。不注入真实值；命中已存凭证时按 fail-closed 拦截（命令会以空值/默认值照常执行，清环境 wrapper 内层同样取不到）。
- **回填**：已存凭证的明文被误写进命令时，机械替换回 `$NAME` 引用的动作。反查数据源是本 session 累积的凭证值表（forget 后旧值仍回填，deliberate fail-closed）；只作用于裸 token 位置。
- **数据位**：命令文本中「引号字符串 / heredoc / 命令替换」等属数据语义的位置。回填不在数据位改写，命中即拦截（防静默篡改命令数据）。
- **注入规划**：纯文本分析模块（`planInjection` / `hasInjectableRef`）：输入命令文本、凭证快照与回填索引，输出拦截文案或注入赋值序列；零 I/O，命令拼装与存储读取归扩展入口。
- **存储保护面**：禁止读写的文件清单（plain 正典 / age 密文 / 身份密钥 / 后端配置 / 删除失败期间的遗留 env）。清单单一来源，路径解析与子串兜底两个比对面共用；新增保护面 = 清单加一行。
